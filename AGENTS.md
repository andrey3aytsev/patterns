# AGENTS.md

Структура проекта и описание паттернов — в [`README.md`](./README.md).

## При добавлении нового паттерна

1. Создать директорию `src/patterns/<pattern>/` с двумя файлами:
   - `<pattern>.ts` — реализация паттерна.
   - `index.ts` — небольшая демка, которая запускается при импорте файла.
2. Добавить запись в объект `PATTERNS` в `src/index.ts`, сохраняя порядок и формат соседних строк.
3. Обновить `README.md`:
   - добавить директорию в дерево раздела `Структура`;
   - добавить пункт с кратким описанием в нужную категорию раздела `Паттерны` (`Порождающие` / `Структурные` / `Поведенческие`).

## Общие правила

- Переиспользовать общие модели из `src/patterns/models/` — не дублировать их в реализации паттерна.
- Описание паттерна в `README.md` должно соответствовать коду: упоминаемые классы и интерфейсы должны существовать, а перечисленные продукты — реально создаваться/использоваться клиентом.
- Запуск проверять командой `npm start -- <pattern>`.
